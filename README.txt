SPENDING – SIMPLE PERSONAL EXPENSE TRACKER

What's included
- Add, edit and delete expenses
- Monthly totals, expense count, average per expense and average per day
- Browse monthly history
- Export the selected month as CSV
- Download/restore a full JSON backup
- Installable PWA with offline support after first load

IMPORTANT DATA NOTE
Your records are saved in this browser on this device using localStorage. There is no account, bank connection, cloud sync, or server-side backup. Use Download backup regularly. Clearing browser site data can erase records. To move devices, download a backup on the old device and restore it on the new one.

HOW TO PUT IT ON YOUR ANDROID HOME SCREEN
1. Host the contents of this folder on a free HTTPS static host (GitHub Pages is one option).
2. Open the published website in Chrome on Android.
3. Open Chrome's three-dot menu and choose "Install app" or "Add to Home screen".
4. Confirm. The Spending icon will appear with your other apps.

For the first version, no personal spending records are preloaded. Start fresh by adding expenses.
